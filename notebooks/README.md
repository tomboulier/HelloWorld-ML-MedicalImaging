# The starting point

`tuto-hello-world-deep-learning-medical-imaging.ipynb` is the notebook this
repository started from in April 2021: a transcription of the tutorial by
Lakhani et al. (Journal of Digital Imaging, 2018,
<https://doi.org/10.1007/s10278-018-0079-6>) with Keras. It was deleted from
the repository in March 2022 once its code had been moved into modules, and is
restored here from the Git history as the first step of the roadmap.

Its outputs were stripped: they contained two radiographs from the dataset,
which is not stored in this repository (see the README). The code and text are
unchanged, so the notebook still uses the Keras 2 API of 2021 and is not meant
to be run with the current environment; the same pipeline, with the current
API, is in `src/hello_world_medical_imaging/`.
