# Architecture decision records

An architecture decision record (ADR) is a short text that captures one
decision, its context and its consequences, so that the next person
(including the author, a year later) knows why the code looks the way it does.
The format is the one proposed by Michael Nygard (see <https://adr.github.io/>).
A record is never edited after it is accepted: a later decision supersedes it
with a new record.
